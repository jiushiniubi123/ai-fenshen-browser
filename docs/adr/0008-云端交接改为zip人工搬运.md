# 0008 - 云端交接改为 zip 人工搬运，撤销令牌直连

日期：2026-09-12 ｜ 状态：已接受（用户决策）｜ 取代：ADR 0006

云端沙箱（Z.ai 网页版，GLM-5.3）**不再对接 GitHub**：不发令牌、不 clone、不 commit、不 push。任务交接改为人工搬运 zip 两个方向：

- **上行（本机 → 云端）**：本机 agent 生成一个「仓库快照 zip」——仓库 tracked 文件（`CONTEXT.md`、`AGENTS.md`、`CLAUDE.md`、`docs/`、`skills/` 等）外加任务书 `TASK.md`；用户把 zip 上传到 Z.ai 对话框，再粘一句短提示词让云端读 `TASK.md` 照做。
- **下行（云端 → 本机）**：云端把写好的源码打成 zip，用户下载后交给本机 agent；本机 agent 解压 → 白名单校验 → 提交推送。

## 为什么改

- 令牌是长期有效的高权限凭证，而它必须明文出现在云端对话里才能用；zip 搬运让**流程里不再存在任何凭证**，暴露面归零。
- 推什么由本机决定：云端只交文件，进不进仓库、进哪些文件，由本机把关。

## 代价（已接受）

- 每次任务多两步人工：上传一个 zip、下载一个 zip。用户侧指令仍保持复制粘贴级。
- **快照即事实**：zip 打好那一刻的仓库内容就是云端的全部输入，之后本机的新提交云端看不到；需要新内容就得重打快照。
- ADR 0006 里「仓库公开」的理由（让云端能读）随之消失。仓库**保持公开**（现状不动，内含无敏感信息），但公开已不再是流程需要。

## 纪律

- 快照 zip 按**白名单**复制（脚本 `.scratch/make-upload-zip.py`，走 `git ls-files` 只取 tracked 文件），**绝不含**令牌、keystore、`local.properties`、`docs/install-ledger.md`、`.scratch/` 其余内容。
- 回流 zip 只允许新增/覆盖任务书点名的交付物（如 `app/`、`README-BUILD.md`）；`docs/`、`skills/`、`AGENTS.md`、`CLAUDE.md`、`CONTEXT.md`、`NEXT.md` 一律不许被云端改动，越界即拒收。
- 旧任务书（`.scratch/issue3-sandbox-brief.md`）里填过的万能令牌**作废**：任务书已重写为无令牌版，令牌须到 GitHub 后台吊销重发（本机人工步骤，见 `NEXT.md` 用户侧待办）。

## Considered Options

- **维持 ADR 0006（公开仓库 + 令牌直连）**：最省人工，但凭证长期有效且必须明文出现在云端对话里，被否（用户决策）。
- **私有仓库 + 令牌直连**：暴露面一样，还要多配一套权限，被否。
- **只发任务书文本、不搬仓库快照**：云端读不到 `CONTEXT.md` 术语表与 `skills/` 手册，等于废掉 ADR 0007 的过程纪律，被否。
- **zip 人工搬运（本 ADR）**：零凭证、推什么由本机把关；代价是每次两次人工搬运，接受。
