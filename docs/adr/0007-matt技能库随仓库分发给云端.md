# 0007 - matt 技能库随仓库分发，云端照 SKILL.md 执行

日期：2026-09-12 ｜ 状态：已接受（用户决策）

背景：ADR 0005 曾规定"matt skills 只在本机存在，云端只产出代码"。用户 2026-09-12 决定升级：整套 matt skills（30 个技能，源 `C:\Users\A\.zcode\skills\`，约 236KB 纯文档）以**只读快照**形式入库 `skills/`，云端沙箱写码时把对应 SKILL.md 当操作手册照做——让云端不只交代码，还交过程纪律（小步切片、Standards/Spec 自查、上下文卫生）。

约定：

- `skills/` 是随仓库分发的只读快照，唯一可变来源是本机 `C:\Users\A\.zcode\skills\`；本机 agent 更新技能后负责重新同步入库，云端不得修改 `skills/`。
- 云端"使用技能"＝读对应 SKILL.md 并照做（沙箱无技能运行时）：开工先读 `skills/ask-matt/SKILL.md` 选路，写码按 `skills/implement/SKILL.md`，入口规则见 `skills/README.md`。
- 沙箱裁剪：跳过一切需要构建环境的步骤（运行构建/测试/模拟器/截图），改为在交付文档里输出"本机待验证清单"；这些执行环节仍按 ADR 0005 在本机做。
- 任务书（`.scratch/` 模板）必须含技能要求：克隆后先读 `skills/README.md`，写码照 `skills/implement/SKILL.md`。
- 安全核查（入库时已做）：技能文件无 GitHub 令牌、无本项目专属隐私；`skills/` 不在 .gitignore；ZCode 插件（github、android-emulator 等）仍只在本机。

## Considered Options

- **维持技能全在本机（0005 原状）**：云端写码没有过程纪律约束，质量全靠任务书单点约束，被否。
- **只入库云端用得到的少数技能**：切片维护成本高、快照不完整反而误导选路，被否。
- **整库快照入库 + 云端按手册执行（本 ADR）**：一次同步、选路完整、本机仍保运行时优势，接受。
