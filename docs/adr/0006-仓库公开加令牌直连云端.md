# 0006 - 仓库公开 + 令牌直连云端

日期：2026-09-12 ｜ 状态：已接受

仓库 jiushiniubi123/ai-fenshen-browser 转为**公开**，并作为云端流水线的传输通道：Z.ai 沙箱（GLM-5.3）凭用户手工创建的短期 fine-grained 令牌（仅此仓库、仅 Contents 读写、7 天有效、用完即吊销）直接 clone → commit → push，取代 ADR 0005 的 zip 回流。云端由此能直接读到 CONTEXT.md / ADR / build-recipe，代码与文档全程同源；GitHub 即云端仓库，不存在第二份副本。

## 安全纪律（随公开仓库永久生效）

- 本仓库全世界可见，git 历史无法真正删除：**任何密钥、令牌、keystore、local.properties 绝不提交进本仓库**。
- 令牌只允许存在于两处：Z.ai 对话内、本地 `.scratch/` 的任务书槽位（不入库）。绝不写入仓库内任何文件或 commit message。
- 每个云端任务用一把新令牌（单仓库 + Contents 读写 + 7 天），任务验收后立即吊销。

## Considered Options

- **保持私有 + zip 回流**：零暴露，但每次人工搬运 zip，且云端读不到项目记忆，被否（用户拍板公开+直连）。
- **私有仓库 + 令牌直连**：沙箱读写同样需要令牌，暴露面不比公开方案小，反而多一层"读也要钥匙"的复杂度，被否。
