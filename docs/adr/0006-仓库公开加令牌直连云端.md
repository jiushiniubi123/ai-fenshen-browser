# 0006 - 仓库公开加令牌直连云端

日期：2026-09-12（同日修订：凭证由每任务一次性细粒度卡改为万能令牌，用户拍板）｜ 状态：已接受

仓库 jiushiniubi123/ai-fenshen-browser 为**公开**，并作为云端流水线的传输通道：Z.ai 沙箱（GLM-5.3）凭用户的**万能令牌**（classic PAT）直接 clone → commit → push，云端由此能直接读到 CONTEXT.md / ADR / build-recipe，代码与文档全程同源；GitHub 即云端仓库，不存在第二份副本。

## 安全纪律（随公开仓库永久生效）

- 本仓库全世界可见，git 历史无法真正删除：**任何密钥、令牌、keystore、local.properties 绝不提交进本仓库**。
- 万能令牌只允许存在于两处：Z.ai 对话内、本地 `.scratch/` 的任务书槽位（不入库）。绝不写入仓库内任何文件或 commit message。
- 一旦怀疑令牌泄露（出现来历不明的提交、令牌出现在任何公开处），立即到 GitHub 后台吊销并重新签发。

## Considered Options

- **保持私有 + zip 回流**：零暴露，但每次人工搬运 zip，且云端读不到项目记忆，被否（用户拍板公开+直连）。
- **私有仓库 + 令牌直连**：沙箱读写同样需要令牌，暴露面不比公开方案小，反而多一层"读也要钥匙"的复杂度，被否。
- **每任务一次性细粒度卡（本 ADR 初版）**：仅此仓库、7 天、用完即吊销，暴露面最小；但每次任务都要本人手工走 9 步建卡+吊销，太麻烦，被否（2026-09-12 修订）。
- **长期仓库专用卡**：只建一次、长期只开这一个仓库，省事与暴露面折中；用户仍选更省事的万能令牌直给，被否。
