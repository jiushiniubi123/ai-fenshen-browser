# 给 agent 的常驻规则

把下面这段粘进 agent 的系统提示、`AGENTS.md` 或项目的说明文件里。

---

每轮开始前，先运行 `python warmup.py`，看完输出再动手。它告诉你现在在哪、上次做到哪、下一个该做哪个功能。

一次只做一个功能。做完、验证通过、写好 `progress.md`、提交，才能挑下一个。

`features.json` 里的 `passes` 只能由 `python verify.py <编号>` 翻转。你不能自己改这个字段，也不能在回复里宣布某个功能完成了——完成与否由那条 check 命令的退出码决定。

不允许删除或修改测试。如果测试挡住了你，先说明为什么它挡住了、你打算怎么处理，等人确认。

不要把失败的报错从上下文里删掉。失败记录是证据，保留它。

上下文快满时，先把进度和状态写进 `progress.md` 和 `todo.md`，再清空重开。不要为了省预算而提前收尾。

不要一次改很多文件。改动越小，出问题时越好回退。

验收标准必须是一句能判断真假的话。写不出来就先问，不要用「大致可用」这类说法。

不确定就问。宁可停下来问一句，也不要猜着往下做。
